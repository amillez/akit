### Bootstrap an empty app

**You own the tree and the startup order.** Stand up an empty Expo app with house tooling that runs in a dev client on iOS and Android. Every later playbook assumes this shape.

Use it for a new app, or to bring an app that never had the house layout up to it. The decisions live in rn-bedrock. [`examples/bedrock/`](https://github.com/amillez/rn-bedrock/tree/main/examples/bedrock) is the working reference. Copy its shape, not its product.

**Hard don'ts.** Each one is in rn-bedrock [`AGENTS.md` § Hard invariants](https://github.com/amillez/rn-bedrock/blob/main/AGENTS.md#hard-invariants) or [`docs/architecture.md` § Boundaries that hold](https://github.com/amillez/rn-bedrock/blob/main/docs/architecture.md#boundaries-that-hold).

- No import before `./polyfills` in `src/main.ts`.
- No `libs/http/`, no injected HTTP adapter, no axios. The `fetch` replacement is a global polyfill.
- No `components/` folder or `.tsx` file under `src/modules/`.
- No hand edits in `ios/` or `android/`. They are prebuild output and gitignored.
- No Expo Go. The stack has native code from the first commit (`react-native-nitro-fetch`).
- None of the five libraries agents wrongly assume: Unistyles, NativeWind, Expo Router, axios, FlashList.
- No change to Metro, Babel, or a pinned version before you read [`docs/workarounds.md`](https://github.com/amillez/rn-bedrock/blob/main/docs/workarounds.md).

1. Read, in order: [`AGENTS.md`](https://github.com/amillez/rn-bedrock/blob/main/AGENTS.md), [`docs/architecture.md` § The shape](https://github.com/amillez/rn-bedrock/blob/main/docs/architecture.md#the-shape) and [§ Bootstrap order](https://github.com/amillez/rn-bedrock/blob/main/docs/architecture.md#bootstrap-order), [`docs/tooling.md`](https://github.com/amillez/rn-bedrock/blob/main/docs/tooling.md), [`docs/stack.md` § Platform](https://github.com/amillez/rn-bedrock/blob/main/docs/stack.md#platform) and [§ Pins worth knowing about](https://github.com/amillez/rn-bedrock/blob/main/docs/stack.md#pins-worth-knowing-about), and [`docs/workarounds.md`](https://github.com/amillez/rn-bedrock/blob/main/docs/workarounds.md).
2. Create the project with pnpm on the Expo SDK, React Native, and React versions in `docs/stack.md` § Platform. Set `"main": "./src/main.ts"` and copy the script names from [`docs/tooling.md` § Commands](https://github.com/amillez/rn-bedrock/blob/main/docs/tooling.md#commands). `start` runs `expo start --dev-client`. Pin `react-native-reanimated` and `react-native-worklets` at the exact versions `docs/stack.md` names.
3. Lay out the canonical tree from `docs/architecture.md` § The shape: `src/main.ts`, `src/polyfills/`, `src/libs/`, `src/modules/`, `src/utils/`, and `src/ui/` with `providers.tsx`, `navigator.tsx`, `screens/`, `components/`, `navigation/`, `locale/`, and `query/`. Add `plugins/`, `global.css`, and `app.config.ts` at the root.
4. Write the entry per [§ 1. Polyfills before anything else](https://github.com/amillez/rn-bedrock/blob/main/docs/architecture.md#1-polyfills-before-anything-else). `src/main.ts` imports `./polyfills`, then calls `registerRootComponent`, and nothing else. `src/polyfills/` assigns the `react-native-nitro-fetch` exports to `globalThis.fetch`, `Headers`, `Request`, and `Response`.
5. Compose the providers outermost first in `src/ui/providers.tsx` per [§ 2. Providers, outermost first](https://github.com/amillez/rn-bedrock/blob/main/docs/architecture.md#2-providers-outermost-first). The gesture handler root wraps everything. Config wraps every provider that reads config. Safe-area mounts before the listener that publishes insets to uniwind. The overlay host mounts last. Sheets need no provider. Match the order and comment in the example's `src/ui/providers.tsx`.
6. Gate startup per [§ 3. Startup gates, each degrading alone](https://github.com/amillez/rn-bedrock/blob/main/docs/architecture.md#3-startup-gates-each-degrading-alone). Hold the splash on independent gates that each resolve true on failure. Only fonts and i18n block the first paint. Put the error boundary outside `Providers`, so its fallback uses nothing a provider supplies. See the example's `src/ui/app.tsx`.
7. Configure TypeScript per [`docs/tooling.md` § TypeScript](https://github.com/amillez/rn-bedrock/blob/main/docs/tooling.md#typescript). Extend `expo/tsconfig.base` with `strict`, `noUncheckedIndexedAccess`, and `noImplicitOverride`. Map `~/*` to `./src/*`, and make Babel, Metro, and Jest's `moduleNameMapper` resolve the same alias. Type `EXPO_PUBLIC_*` in `types/env.d.ts` and keep `.env.example` in step.
8. Configure Metro per [`docs/tooling.md` § Metro](https://github.com/amillez/rn-bedrock/blob/main/docs/tooling.md#metro). Use `getSentryExpoConfig(__dirname)` as the base once the app has Sentry. Until then use `getDefaultConfig`, as the example does. `withUniwindConfig` is the outermost wrapper. Invert that order only when Worklets Bundle Mode is in the tree, per [workarounds § Bundle Mode and uniwind resolution deadlock](https://github.com/amillez/rn-bedrock/blob/main/docs/workarounds.md#bundle-mode-and-uniwind-resolution-deadlock). A custom `resolveRequest` captures the previous one and falls back to it.
9. Keep Babel minimal per [`docs/tooling.md` § Babel](https://github.com/amillez/rn-bedrock/blob/main/docs/tooling.md#babel). Use `babel-preset-expo` with `unstable_transformImportMeta: true`, plus `transform-remove-console` in production. Do not add the worklets or reanimated plugin by hand.
10. Set up logic-only Jest: Node environment, `ts-jest`, and `*.spec.ts` only. Copy the example's `jest.config.ts` and keep its `testMatch`.
11. Keep native config in `app.config.ts` per [`docs/tooling.md` § Native builds and release](https://github.com/amillez/rn-bedrock/blob/main/docs/tooling.md#native-builds-and-release). Config plugins go in `plugins/with-*.js` and read build-time data from `app.config.ts`. Gitignore `ios/` and `android/`. After any native change, run `pnpm prebuild`. Use one scheme everywhere it appears.
12. Add `expo-dev-client`. Build and run with `pnpm ios` and `pnpm android`. Add `eas.json` for EAS builds. Allowlist in pnpm every dependency lifecycle script that must run at install, since pnpm blocks them by default.
13. Pick each library from the `docs/stack.md` § By layer table. Before you add or swap one, read its entry in [`docs/packages/`](https://github.com/amillez/rn-bedrock/blob/main/docs/packages/README.md) and its **Rejected** list.
14. Verify. Run `pnpm typecheck` and `pnpm test`. Confirm that `src/modules/` holds no `.tsx` file and that the first import in `src/main.ts` is `./polyfills`. Build the dev client on an iOS simulator and an Android emulator, and prove the first screen renders after the splash hides, per the proof rules in `amillez-mode`. Then tear down.

The domain, data, UI, and product-SDK layers are later playbooks. A bootstrap PR stops at an app that starts, renders one screen, and passes typecheck and tests.

**Reply:** the tree you created, the provider order and gates, any pin or workaround you kept and its removal condition, and the proof links for both platforms.
