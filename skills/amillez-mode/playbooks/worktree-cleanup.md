### Worktree and simulator cleanup

**You own the disk and the safety gate.** Prune merged or abandoned git worktrees, their local branches, stale simulators and emulators, and leftover Metro and Expo processes. Deletion is irreversible, so every step guards against deleting something in use or holding uncommitted work.

1. Snapshot and audit. Record `df -h ~`, then run [`scripts/worktree-audit.sh`](../scripts/worktree-audit.sh) ([Build the Lever](../principles/build-the-lever.md)). Pass the repos to audit, or `--root DIR` for a directory of checkouts (default `$AGENT_WORK_ROOT`, else `~/agent-work`). Add `--fetch` when the MERGED column must reflect the latest `main`. The script reads paths from `git worktree list`, never hand-typed ones, since a hand-typed path misses a worktree that lives somewhere else ([Encode Lessons in Structure](../principles/encode-lessons-in-structure.md)). It classifies each worktree by size, age, merge state, uncommitted work, remote and PR state, and last local activity, then suggests a bucket. It also lists listening Metro and Expo ports, Expo CLI processes, booted simulators, and running emulators. It only reads.
2. The bucket is advice, not permission. The real in-use set is the running agent sessions, open PRs, and the dispatcher's active work ([Prove It Works](../principles/prove-it-works.md)). Get that set and cross-check every candidate against it. An in-use worktree wins over any bucket.
3. Verify usage before deleting. For every `verify-recent` or `hold-open-pr` row, or anything you doubt, confirm which session or PR owns it. `gh pr view <branch>` gives the PR state. A worktree whose PR is open stays unless its owner is done with it.
4. Pause on irreversible loss. `wip:N` is N tracked uncommitted edits. Show `git -C <path> diff` and get a decision first, since removing a clean worktree is recoverable from its branch but uncommitted work is gone. `scratch:N` is untracked throwaway, safe to drop, but name the files. Clean, merged, and not in use proceeds. `wip` and in-use pause.
5. Prune the confirmed set. Per path, `git worktree remove <path>`, adding `--force` only for a path you confirmed in step 4. If the dir survives on ignored build artifacts, remove the dir, then `git worktree prune`. `prunable` rows need only the prune. Delete a local branch only when its PR merged or the work was abandoned: `git branch -d <branch>` for merged, `-D` only after step 4 confirmed abandon. Remote branches stay. Confirm with `df -h ~` and re-run the audit.
6. Simulators and emulators. Simulators are usually the next-biggest win. When `simfleet serve` is up, read `simfleet status` and `simfleet agents` first, skip devices another live session has claimed, and shut down the rest with `simfleet sim shutdown` and `simfleet emu shutdown` per the `simfleet` skill. Otherwise, `xcrun simctl shutdown all`, `xcrun simctl --set testing delete all` (test device clones), `xcrun simctl delete unavailable`, and `xcrun simctl runtime list` then `xcrun simctl runtime delete <id>` for old runtimes. Android: `adb devices`, then `adb -s <serial> emu kill` for each emulator you started, and `avdmanager list avd` then `avdmanager delete avd -n <name>` for AVDs nobody uses.
7. Metro and Expo. Stop simfleet lanes with `simfleet lane stop <lane-id>`, never by killing their Metro. Stop other Metro, dev servers, and matching `expo/bin/cli`, `expo start`, and `expo run` processes that no in-use worktree owns. Then check that no used Metro port is listening (`lsof -nP -iTCP:8081 -sTCP:LISTEN`, same for 8090).
8. Other reclaimers, when needed. Xcode `DerivedData` and `iOS DeviceSupport`, Gradle caches, and package caches (pnpm, yarn, npm, uv, brew). Clear only caches Agustín has not said to keep.

This is the one playbook that deletes local state with no code review to catch a slip, so the gates above are the review.

**Reply:** `df -h ~` before and after with space reclaimed, the worktrees and branches pruned, simulators, emulators, and processes stopped or deleted, the port check result, and a one-line reason for each item held back (in use by which session or PR, or uncommitted work).
